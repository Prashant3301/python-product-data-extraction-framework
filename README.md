# Python Product Data Extraction Framework

A Python automation framework for large-scale product catalog discovery and detail extraction.

## Features

- Selenium automation
- BeautifulSoup parsing
- Retry mechanism
- Browser recovery
- Checkpoint support
- Resume capability
- Excel reporting

## Installation

pip install -r requirements.txt

## Run Phase 1

python phase1/collect_product_urls.py

## Run Phase 2

python phase2/extract_product_details.py
